# gblog — 구글 타깃 제휴 블로그 (Hugo + GitHub Pages + 쿠팡파트너스)

네이버 자동 발행 차단 이후의 대안 트랙. 자세한 방침은 `CLAUDE.md`.

## 왜 이 조합인가
| 선택지 | 자동 발행 | 비용 | AI 리스크 | 판단 |
|---|---|---|---|---|
| 네이버 블로그 | 봇 발행 → 검색 차단 실측 | 0 | 높음 | 사람 발행 실험 중(~/naver) |
| 티스토리 | Open API 종료(2024) → 봇 필요 | 0 | 네이버와 동일 | 제외 |
| 워드프레스(자가호스팅) | REST API 합법 | 호스팅 유료 | 없음 | 비용 때문에 보류 |
| **Hugo + GitHub Pages** | **git push = 발행(합법)** | **0** | **없음(내 사이트)** | **채택** |

## 계획 (순서)
1. 쿠팡파트너스 가입·승인 (사용자)
2. Hugo 사이트 골격 + GitHub Pages 배포 + 도메인(선택)
3. naverauto 파이프라인 이식: 키워드(구글 트렌드/서제스트 기반으로 교체) → 리서치 → 구매 사슬 → 글 생성 → 차트 → 팩트체크 → Hugo 마크다운 출력 → git push 발행
4. SEO: 메타/OG/구조화 데이터(Product·FAQ), sitemap, Search Console 등록
5. 저속 운영(주 2~3편) + Search Console 노출 모니터링
